# BlockPrompt 1.2

1.2는 휴대폰에서 긴 Prompt를 편집하고, 생성 결과를 다시 찾고, 재사용 가능한 자료를 정리하는 흐름을 크게 다듬은 버전입니다.

## 주요 변경사항

- History 상단의 `기록`/`즐겨찾기`를 고정하고 각각의 스크롤 위치를 기억합니다. 설정된 기록 개수를 벗어난 항목도 즐겨찾기라면 계속 보존됩니다.
- 생성물 저장 폴더 전체를 날짜별로 보는 갤러리를 추가했습니다. PNG metadata를 로컬에 색인해 태그, 날짜 범위, 모델, Sampler, Steps, Guidance, Rescale 조건으로 검색할 수 있습니다.
- 갤러리에서 이미지를 길게 눌러 여러 장을 선택하고 날짜 또는 검색 결과 전체를 삭제할 수 있습니다. 삭제 시 원본, 갤러리 색인과 연결된 History를 함께 정리합니다.
- 생성 결과와 갤러리 상세 화면의 이미지 탭, 전체 화면 보기, Prompt 보기, Prompt 비교, 이미지 비교, Image2Image 사용, 전체/일부 Prompt 가져오기 흐름을 통일했습니다.
- Prompt 일부 가져오기는 기존 작업을 교체하지 않고 선택한 Block만 원하는 Base/Character와 Positive/Negative에 추가합니다. 가져온 Block은 현재 Base 배율과 무관하게 `사용자 지정 ×1.0`으로 추가됩니다.
- Prompt와 생성 설정을 가져올 때 마지막 선택 항목을 기억합니다. Base Positive/Negative, Character, 생성 설정, Seed, 입력 이미지와 Character 교체/추가 방식을 다음 가져오기에도 재사용합니다.
- History 복원은 원래 Block 구조와 기본 배율을 유지합니다. 새 History는 Wildcard 원문과 당시 선택된 결과를 모두 Block 단위로 보존합니다.
- 자동완성은 Local / NovelAI / Danbooru 중 한 출처만 compact하게 표시하며, 탭 또는 한 칸씩 움직이는 세로 제스처로 출처를 바꿀 수 있습니다.
- 자동완성·Undo 도구 위치를 상단 고정, 하단 고정, 유동 배치로 선택할 수 있으며, 표시와 출처 전환이 편집 화면의 스크롤 위치를 바꾸지 않도록 보강했습니다.
- Wildcard에 쉼표 구분 별명을 추가했습니다. `__` 뒤에 이름 또는 별명을 한 글자부터 입력해 `__name__` 형식으로 자동완성할 수 있습니다.
- Wildcard 후보 편집 화면에 행 구분과 교대 배경을 추가하고, 후보 선택이 고정 Seed에서도 생성마다 다시 뽑히도록 수정했습니다.
- Library와 Wildcard의 폴더 선택 UI를 통일했습니다. 빈 폴더도 유지하며 새 폴더 생성, 항목 수 표시, 길게 눌러 이름 변경·삭제를 지원합니다.
- Wildcard 목록은 길게 눌러 다중 선택 삭제가 가능하고, 개별 삭제는 편집 화면에서 할 수 있습니다.
- PNG metadata 해석과 검색 색인을 보강하고, 긴 Prompt·키보드·앱 백그라운드 복귀·화면 전환에서 발생하던 위치 및 상태 복원 문제를 수정했습니다.

## 설치 및 데이터

- Android 6.0(API 23) 이상과 본인의 NovelAI 계정 및 Token이 필요합니다.
- 기존 공식 서명 APK 위에는 같은 서명의 1.2 APK를 덮어쓸 수 있습니다. Debug APK와 Release APK 사이를 전환할 때는 백업 후 기존 앱 제거가 필요할 수 있습니다.
- 1.2는 로컬 DB를 version 19로 마이그레이션합니다. 업데이트 전 중요한 작업과 사용자 데이터는 앱의 전체 백업으로 별도 보관하는 것을 권장합니다.
- 전체 백업에는 Session, Stash, Library, History metadata와 미리보기, 사용자 Tag DB, Wildcard 및 설정이 포함됩니다. NovelAI Token과 생성 원본 이미지는 포함되지 않습니다.

## 알려진 제한

- 생성 폴더 검색은 PNG에 포함된 NovelAI metadata를 사용합니다. JPEG/WebP 또는 metadata가 없는 PNG는 날짜별 열람은 가능하지만 Prompt 태그 검색 대상에는 포함되지 않습니다.
- 기존 1.2 이전 History에는 Block별 Wildcard 선택 결과가 없으므로, 해당 항목에서 선택 결과 복원을 요청하면 Block 구조를 보호하기 위해 Wildcard 원문 세션으로 복원합니다.
- 모델별 지원 옵션과 비용 표시는 NovelAI 동작 변경에 따라 달라질 수 있습니다.
- 실험적 Token/Anlas 추정은 참고용이며 생성을 차단하지 않습니다.
- Inpaint는 V5 Full 실기기에서 확인했으며 V4.5 Full과 모든 해상도·마스크 조합을 검증한 것은 아닙니다.
