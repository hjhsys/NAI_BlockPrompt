# BlockPrompt 1.1

1.0 이후 실제 휴대폰 사용에서 발견한 Prompt 편집, 비교, 가져오기, 키보드 및 긴 Block 조작 문제를 중심으로 다듬은 버전입니다.

## 주요 변경사항

- Prompt Block Undo에 Redo를 추가하고, 커서 위치의 Block 분리와 바로 위 Block 결합을 지원합니다.
- Quick Edit에 다중 선택, 묶음 이동·삭제·주석, 줄바꿈, 붙여넣기, 태그 사전 삽입, 태그 정보 확인을 추가했습니다.
- 같은 가중치의 여러 선택을 함께 조절할 수 있고, `+`/`−` 길게 누르기 반복과 가중치 부호 반전을 지원합니다. 길게 누르기 판정 시간과 반복 간격은 Settings에서 조절할 수 있습니다.
- Prompt 도구가 화면 밖으로 나갔을 때 Undo/Redo/Quick Edit와 자동완성을 표시하는 compact overlay를 추가했습니다. 자동완성·도구 위치는 상단 고정, 하단 고정, 유동 배치 중 선택할 수 있습니다.
- 자동완성은 Local / NovelAI / Danbooru 중 한 출처를 한 줄에 표시하고 탭 또는 세로 제스처로 전환합니다. 현재 쉼표·줄바꿈 단위 조각을 교체하며, 긴 에디터와 키보드에서도 커서 및 스크롤 상태를 최대한 유지합니다.
- Character Positioning은 번호 선택 후 탭 배치와 선택된 마커 드래그를 지원합니다.
- 외부 PNG의 Prompt와 생성 설정을 가져오기 전에 미리 볼 수 있고, 전체 가져오기와 일부 Block 가져오기를 바로 선택할 수 있습니다. Character Prompt는 현재 Character 교체 또는 뒤에 추가가 가능합니다.
- 생성 전 현재 Prompt 미리보기를 추가했습니다. History의 생성 Prompt 보기에는 모델, 해상도, sampler, steps, guidance, rescale, noise schedule, seed 등 생성 정보를 함께 표시합니다.
- 이미지 A/B 비교와 Prompt·생성 설정 비교를 제공하며, 비교 화면 안에서 이미지 비교와 Prompt 비교를 전환할 수 있습니다.
- Library의 Block Set/Preset 설명과 항목별 미리보기 이미지를 추가했습니다.
- Character 영역의 중립색 교대 배경, compact 하단 내비게이션, 이미지 확대 화면의 여백과 조작 방식을 다듬었습니다.
- History 삭제 시 기록만 삭제하거나 생성 원본도 함께 삭제할 수 있습니다.
- History의 전체/즐겨찾기 필터를 compact 고정 헤더로 바꾸고, 두 필터의 스크롤 위치를 각각 기억합니다.
- 자동완성 fragment 범위 계산을 보강하고 Prompt selection 및 긴 Block 편집 관련 크래시·스크롤 회귀를 수정했습니다.

## 설치 및 데이터

- Android 6.0(API 23) 이상과 본인의 NovelAI 계정 및 Token이 필요합니다.
- 기존 공식 서명 APK 위에는 같은 서명 APK를 덮어쓸 수 있습니다. Debug APK와 Release APK 사이를 전환할 때는 백업 후 기존 앱 제거가 필요할 수 있습니다.
- 전체 백업에는 Session, Stash, Library, History metadata와 미리보기, 사용자 Tag DB, Wildcard 및 설정이 포함됩니다. NovelAI Token과 생성 원본 이미지는 포함되지 않습니다.

## 알려진 제한

- 모델별 지원 옵션과 비용 표시는 NovelAI 동작 변경에 따라 달라질 수 있습니다.
- 실험적 Token/Anlas 추정은 참고용이며 생성을 차단하지 않습니다.
- Inpaint는 V5 Full 실기기에서 확인했으며 V4.5 Full과 모든 해상도·마스크 조합을 검증한 것은 아닙니다.
- 기기별 키보드, 시스템 내비게이션, 백그라운드 복귀 동작은 계속 실기기 회귀 확인이 필요합니다.
