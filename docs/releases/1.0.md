# BlockPrompt 1.0

휴대폰에서 NovelAI 프롬프트를 Block 단위로 작성·관리하는 비공식 Android 앱의 첫 릴리즈입니다.

- Base / Character별 Positive·Negative 편집, Block 저장·정렬·잠금, Library
- Prompt Undo, 가중치 전체 구간 강조, 빠른 Tag/Chunk 선택·가중치·주석·삭제·이동
- 커서 위치에서 Block 나누기와 같은 영역의 위 Block과 합치기
- Image2Image, Vibe Transfer, Precise Reference, Inpaint, History 및 PNG metadata 가져오기
- Random/Fixed Seed 빠른 전환과 History Seed-only 불러오기
- 201,273개 기본 태그와 한국어 검색, 자동완성, 사용자 번역 및 태그 DB 공유
- Wildcard, 선택형 토큰 추정, 드래그 가능한 DB·Color Helper 바로가기
- AI 번역 범위 선택(`미번역만` / `선택만` / `미번역 + 선택`), JSONL/ZIP 교환, 판단 불가 항목 보류
- AI/사용자 제외 출처 보존, 필터·다중 선택·확정/확정 해제·복구 확인
- 사용자 데이터 백업·복원 및 한국어/영어·밝게/어둡게 테마
- 휴대폰 하단 시스템 영역을 고려한 compact navigation

## 설치

`BlockPrompt-1.0.apk`를 설치하세요. Android 6.0(API 23) 이상, 본인의 NovelAI 계정과 Token이 필요합니다. 모델별 기능 지원은 다릅니다.

기존 **debug APK와 서명이 다릅니다**. 교체 전 앱 백업과 원본·레퍼런스 이미지를 별도로 보관하세요. 기존 앱 제거 후 설치·복원하고 Token과 저장 폴더 권한을 다시 설정해야 합니다. 백업에는 원본 PNG, History/태그 썸네일, Token이 포함되지 않습니다.

APK는 개발자 키로 서명했지만 Google의 별도 인증을 받은 것은 아닙니다. 사이드로드 보안 경고가 나올 수 있습니다.

## 제한 및 검증 범위

- 토큰/Anlas 표시는 모든 모델·조합에서 정확한 값을 보장하지 않습니다.
- 백업 복원은 DB와 설정 사이에 부분 적용될 수 있습니다. 중요한 데이터의 유일한 보관 수단으로 사용하지 마세요. 새 백업은 OOM 방지를 위해 이미지·썸네일 bytes를 넣지 않으며 이전 media 포함 백업의 Import 호환성만 유지합니다.
- Wildcard TXT Export, 전용 폴더 관리, Redo는 제공하지 않습니다.
- Inpaint는 V5 Full 실기기에서 경계 artifact가 사라진 것을 확인했지만 V4.5 Full과 다양한 마스크/해상도는 추가 검증이 필요합니다.
- 자동 테스트와 서명 검증을 수행했습니다. 모든 기기·모델 조합 및 실제 기기 이전을 검증한 것은 아닙니다.
