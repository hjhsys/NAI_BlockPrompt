# BlockPrompt 1.0

휴대폰에서 NovelAI 프롬프트를 Block 단위로 작성·관리하는 비공식 Android 앱의 첫 릴리즈입니다.

- Base / Character별 Positive·Negative 편집, Block 저장·정렬·잠금, Library
- Image2Image, Vibe Transfer, Precise Reference, History 및 PNG metadata 가져오기
- 201,273개 기본 태그와 한국어 검색, 자동완성, 사용자 번역 및 태그 DB 공유
- Wildcard, 선택형 토큰 추정, 드래그 가능한 DB·Color Helper 바로가기
- AI 번역 JSONL/ZIP 교환, 오타 삭제 확인, 판단 불가 항목 보류
- 사용자 데이터 백업·복원 및 한국어/영어·밝게/어둡게 테마
- Generate 하단의 개발용 처리된 Prompt 미리보기 제거

## 설치

`BlockPrompt-1.0.apk`를 설치하세요. Android 6.0(API 23) 이상, 본인의 NovelAI 계정과 Token이 필요합니다. 모델별 기능 지원은 다릅니다.

기존 **debug APK와 서명이 다릅니다**. 교체 전 앱 백업과 원본·레퍼런스 이미지를 별도로 보관하세요. 기존 앱 제거 후 설치·복원하고 Token과 저장 폴더 권한을 다시 설정해야 합니다. 백업에는 원본 PNG와 Token이 포함되지 않습니다.

APK는 개발자 키로 서명했지만 Google의 별도 인증을 받은 것은 아닙니다. 사이드로드 보안 경고가 나올 수 있습니다.

## 제한 및 검증 범위

- 토큰/Anlas 표시는 모든 모델·조합에서 정확한 값을 보장하지 않습니다.
- 백업 복원은 DB와 설정 사이에 부분 적용될 수 있습니다. 중요한 데이터의 유일한 보관 수단으로 사용하지 마세요.
- Wildcard TXT Export, Undo/Redo, Inpaint는 제공하지 않습니다.
- 자동 테스트와 서명 검증을 수행했습니다. 모든 기기·모델 조합 및 실제 기기 이전을 검증한 것은 아닙니다.
